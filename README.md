This is the MedTechLabel Project repository for the information model (WP2 T2.2).
The result will be rendered at https://build.fhir.org/ig/hl7-eu/medtechlabel-wp2-im/

The primary purpose is to collect all items that are mentioned either
in legal requirements or standard documents, organize them into a taxonomy
to help with modelling, and finally to arrange them into an information model.
