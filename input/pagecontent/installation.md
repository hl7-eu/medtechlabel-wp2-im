This "website" is created by running a script (_buidl.bat) that converts 
the different input files into this website.
Therefor, a tool called **IG-publisher** is used.
In the following it is described what is necessary as a precondition
to run the scripts locally.
However, the content is available at [https://build.fhir.org/ig/hl7-eu/medtechlabel-wp2-im/](https://build.fhir.org/ig/hl7-eu/medtechlabel-wp2-im/).


### Necessary Software

The following software (components) are needed.
Installation should be done in the order listed:

* Java SDK (to run the JAR files)
* node.js (basic scripting)
* npm (packaging manager)
* jekyll (to generate and render the website content)
* PlantUML (to help with drawing the UML diagrams)
* SUSHI (to convert the FSH files)
* IG-publisher (to run the publiher izself)

### Software Installation

To run the generation script the necessary software must be installed:

> install Java SDK from official website
> install node.js from official website: [https://nodejs.org/en](https://nodejs.org/en)

Verify that both tools are installed correctly and working:

```
node -v
npm -v
```

> install Ruby from website: [https://rubyinstaller.org/](https://rubyinstaller.org/)

Install SUSHI to convert FSH files to FHIR:

```
npm install -g fsh-sushi
```

Verify that SUSHI is available:

```
sushi -v
```

SUSHI can then be used to create a new empty implementation guide
in the current directory (on command line level):

```
sushi init .
```

Running the build script with option 1 downloads the latest files for the publisher.

### Generating the site

After downloading (or updating) the publisher
the website is generated by running the script (for Windows):

```
_build.bat
```

or for LINUX:

```
_build.sh
```

To generate the site, option **2** must be selected.
Afterwards, the website is available in the **output** directory.

### Results of generation

The result is placed in a subdirectory **output**. 
All previous content will be replaced.

A file called ''full_IG.zip'' contains the complete website. 
It can be extracted into a new (empty) directory. 
The file ''index.html'' should be opened to read the content.
